# MT News — 운영 가이드

> **현재 이 사이트는 기사가 0건인 빈 상태입니다.** 예시 기사와 예시 이미지는 모두 제거되어 있으며,
> `_posts` 폴더에 첫 기사를 올리는 순간 홈·카테고리·태그·RSS가 자동으로 채워집니다.
>
> 올리기 전에 손봐야 할 곳은 세 군데입니다.
> 1. `_config.yml`의 `url:` → 실제 도메인
> 2. `CNAME` 파일 내용 → 실제 도메인
> 3. `about.md`(소개 페이지) → 편집 원칙·소개 문구가 초안으로 들어 있으니 검토 후 수정

의료관광·외국인환자 유치산업 전문 미디어 MT News의 사이트 소스입니다.
GitHub Pages에서 무료로 운영되며, 글은 마크다운 파일 하나를 추가하는 것으로 발행됩니다.

터미널이나 프로그램 설치는 필요하지 않습니다. **모든 작업은 github.com 웹사이트에서 가능합니다.**

---

## 1. 처음 한 번만 하는 설정

### 1-1. 리포지토리 만들고 파일 올리기

1. github.com 로그인 → 우측 상단 `+` → **New repository**
2. Repository name: `mtnews` (아무 이름이나 가능)
3. **Public** 선택 → **Create repository**
4. 만들어진 화면에서 **uploading an existing file** 클릭
5. 압축을 푼 폴더 안의 **파일과 폴더 전체**를 드래그해서 올린 뒤 **Commit changes**

> 폴더 자체가 아니라 **폴더 안의 내용물**을 올려야 합니다.
> `_config.yml`, `index.html`이 리포지토리 최상단에 보이면 맞게 올라간 것입니다.

### 1-2. GitHub Pages 켜기

1. 리포지토리 상단 **Settings** → 왼쪽 메뉴 **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 새로고침하면 `https://아이디.github.io/mtnews/` 주소가 나옵니다

이 시점에서 사이트는 이미 동작합니다.

### 1-3. 구입한 도메인 연결하기

**① 도메인 등록업체(가비아·후이즈·Cloudflare 등) 관리 화면에서 DNS 레코드를 추가합니다.**

| 타입 | 호스트(이름) | 값 |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | **아이디**.github.io |

`아이디` 자리에는 본인의 GitHub 사용자명을 넣습니다. 뒤에 리포지토리 이름은 붙이지 않습니다.

**② GitHub → Settings → Pages → Custom domain** 에 도메인(예: `mtnews.kr`)을 입력하고 Save합니다.

**③ 이 리포지토리의 파일 2개를 수정합니다.**

- `CNAME` — 파일 내용을 실제 도메인 한 줄로 (예: `mtnews.kr`)
- `_config.yml` — `url:` 값을 `https://mtnews.kr` 로

**④ DNS가 퍼지면(보통 10분~1시간, 최대 24시간) Settings → Pages 에서 `Enforce HTTPS`를 체크합니다.**

체크박스가 회색이면 아직 인증서 발급 전입니다. 시간이 지나면 활성화됩니다.

## 2. 기사 올리는 방법

### 2-1. 새 글 쓰기

1. 리포지토리에서 `_posts` 폴더 클릭
2. 우측 상단 **Add file → Create new file**
3. 파일 이름을 아래 규칙으로 입력합니다

```
2026-08-16-medical-visa-reform.md
└─ 발행일 ─┘└─ 영문 소문자 제목(자유) ─┘
```

> **날짜와 확장자(.md)는 반드시 지켜야 합니다.** 파일 이름의 뒷부분이 그대로 기사 주소가 되므로 영문 소문자와 하이픈만 쓰는 것을 권합니다.

4. 아래 형식으로 내용을 작성합니다

```markdown
---
title: "기사 제목"
description: "목록에 노출되는 2~3줄 요약"
category: policy
tags: [메디컬비자, 유치기관]
image: /assets/img/2026-08/사진파일.jpg
image_caption: "사진 설명. ⓒ MT News"
lang: ko
---

여기부터 본문입니다. 빈 줄로 문단을 나눕니다.

## 소제목

문단 내용을 이어서 씁니다.
```

5. 페이지 맨 아래 **Commit changes** 클릭 → **1~2분 뒤 사이트에 반영**

`_drafts/기사-템플릿.md` 파일에 복사해서 쓸 수 있는 서식이 들어 있습니다. `_drafts` 폴더의 글은 사이트에 공개되지 않습니다.

### 2-2. 맨 위 항목 설명 (front matter)

`---` 와 `---` 사이의 항목입니다. 순서는 상관없습니다.

| 항목 | 필수 | 설명 |
|---|---|---|
| `title` | 필수 | 기사 제목. 콜론(`:`)이 들어가면 반드시 큰따옴표로 감쌉니다 |
| `description` | 권장 | 목록·검색결과·SNS 공유에 쓰이는 요약. 없으면 본문 앞부분이 자동 사용됩니다 |
| `category` | 필수 | 아래 8개 중 하나를 **영문 slug로** 씁니다 |
| `tags` | 선택 | `[태그1, 태그2]` 형식. 태그 페이지에 자동 수집됩니다 |
| `image` | 선택 | 대표 이미지 경로. 없으면 목록에서 글자만 표시됩니다 |
| `image_caption` | 선택 | 사진 설명 |
| `lang` | 선택 | 기본 `ko`. 영문 기사는 `en` → 목록에 EN 배지가 붙고 `/en/` 페이지에 모입니다 |
| `author` | 선택 | 기본값은 `_config.yml`의 발행인 이름 |

**카테고리 slug**

메뉴에 나오는 순서와 같습니다.

| 쓰는 값 | 화면 표시 |
|---|---|
| `exchange` | 국제교류 |
| `column` | 칼럼 |
| `policy` | 정책·제도 |
| `stats` | 유치실적·통계 |
| `global` | 글로벌 |
| `medical` | 의료산업 |
| `tourism` | 관광산업 |
| `interview` | 인터뷰 |
| `report` | 리포트 |

> 메뉴 순서를 바꾸려면 `_config.yml`의 `cats:` 목록 순서를 바꾸면 됩니다. 위에서부터 왼쪽 순서입니다.

### 2-3. 사진 올리기

1. `assets/img/` 안의 해당 월 폴더(예: `2026-08`)로 이동합니다. 없으면 새 글 올릴 때 파일명에 `2026-09/사진.jpg`처럼 경로를 쓰면 폴더가 자동 생성됩니다
2. **Add file → Upload files** 로 사진을 올립니다
3. 기사에서 `image: /assets/img/2026-08/사진.jpg` 로 참조합니다
4. 본문 중간에 넣을 때는 `![설명](/assets/img/2026-08/사진.jpg)`

권장 규격: 가로 1600px 내외, 파일 크기 300KB 이하(JPG). 너무 큰 파일은 모바일에서 느려집니다.

### 2-4. 본문에 쓸 수 있는 서식

```markdown
## 소제목          ### 작은 소제목
**굵게**           *기울임*
[링크 글자](https://example.com)
> 인용문
- 목록 항목

| 구분 | 값 |
|---|---|
| 항목 | 31.4% |
```

## 3. 사이트 설정 바꾸기

전부 `_config.yml` 한 파일에서 수정합니다. 수정 후 Commit하면 1~2분 뒤 반영됩니다.

- **뉴스레터 구독 연결** — `subscribe_action:` 에 Formspree·Buttondown 등에서 받은 주소를 넣습니다. 구독 배너는 모든 페이지 하단(푸터 위)에 표시됩니다
- **한 페이지에 보여줄 기사 수** — `paginate:` 값 (기본 8건)
- **카테고리 추가** — `cats:` 에 한 줄 추가 + `category/` 폴더에 기존 파일을 복사해 slug만 바꾼 파일 생성
- **포인트 컬러** — `assets/css/style.css` 최상단 `--accent` 값

> `_config.yml`은 띄어쓰기에 민감합니다. 기존 줄의 들여쓰기를 그대로 따라 하세요.

## 4. 자주 겪는 문제

| 증상 | 원인과 해결 |
|---|---|
| 글을 올렸는데 안 보인다 | 파일명이 `YYYY-MM-DD-제목.md` 형식인지, `_posts` 폴더 안인지 확인 |
| 사이트 전체가 안 뜬다 | `_config.yml` 들여쓰기 오류일 가능성이 큽니다. Actions 탭에서 빨간 X를 눌러 오류 내용 확인 |
| 제목이 깨져 보인다 | 제목에 `:` 나 `"` 가 있으면 `title: "제목: 부제"` 처럼 큰따옴표로 감쌉니다 |
| 이미지가 안 나온다 | 경로가 `/assets/...` 로 시작하는지, 대소문자가 정확한지 확인 |
| 도메인이 연결 안 된다 | DNS 반영에 최대 24시간. `Enforce HTTPS`는 그 이후에 체크 |

발행 상태는 리포지토리 상단 **Actions** 탭에서 확인할 수 있습니다. 초록 체크면 정상 발행입니다.

## 5. 나중에 필요해지면

- **관리자 화면(Decap CMS)** — `/admin` 주소에서 폼으로 글을 쓰는 방식. 마크다운을 몰라도 됩니다
- **검색 노출** — 구글 Search Console과 네이버 서치어드바이저에 사이트 등록 (사이트맵은 `/sitemap.xml`에 자동 생성됨)
- **방문자 통계** — Google Analytics 또는 GoatCounter 삽입
- **사이트 내 검색** — 글이 100편을 넘어가면 검색 기능 추가를 권합니다

## 폴더 구조

```
├── _config.yml          사이트 전체 설정
├── _posts/              ★ 기사가 들어가는 곳 (현재 비어 있음)
├── _drafts/             비공개 초안 + 기사 템플릿
├── _layouts/            페이지 뼈대 (건드릴 일 거의 없음)
├── _includes/           머리말·꼬리말·구독배너 조각
├── assets/css/style.css 디자인
├── assets/img/          이미지
├── category/            카테고리별 목록 페이지
├── index.html           홈
├── tags.html            주제별 보기
├── en.html              영문 기사 모음
├── about.md             소개 페이지
└── CNAME                연결할 도메인
```
